# HMM-GMM Wake Word Detection System

Speech recognition system using MFCC feature extraction and HMM-GMM classification.

## Project Components

### Backend
Contains:
- FastAPI server
- Audio processing
- MFCC extraction
- HMM-GMM classifier
- Wake and non-wake models

### Frontend
Contains:
- Web interface
- Microphone recording
- Waveform visualization
- Spectrogram visualization
- MFCC visualization
- Detection history

## Technologies
- Python
- FastAPI
- Librosa
- HMM-GMM
- JavaScript
- HTML/CSS
