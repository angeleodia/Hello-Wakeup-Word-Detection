HMM-GMM Wake Word Detection System

Project ini merupakan sistem deteksi wake word berbasis:
- MFCC Feature Extraction
- HMM-GMM Classification
- FastAPI Backend
- JavaScript Frontend

Features:
✓ Real-time microphone detection
✓ Waveform visualization
✓ Spectrogram
✓ MFCC visualization
✓ Wake/non-wake classification
